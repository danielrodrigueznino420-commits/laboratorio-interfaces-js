Práctica 03 / Condicionales

La nota final
dice algo.

Registra tres calificaciones entre 0.0 y 5.0. El sistema calcula el promedio, valida las notas y comunica el resultado utilizando una condición if / else.

Registro académico

El promedio mínimo para aprobar es 3.5.

Se aceptan decimales, por ejemplo: 4.2.

Resultado final

El estado cambia según la nota definitiva.

Ingresa las tres notas para calcular el promedio del estudiante.

Condición evaluada

Si la nota definitiva es mayor o igual a 3.5, el estado es APROBADO. En caso contrario, es REPROBADO.

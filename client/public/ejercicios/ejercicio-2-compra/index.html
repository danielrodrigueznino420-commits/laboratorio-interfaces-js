Calcula con intención.

Elige un producto, indica cuántas unidades necesitas y observa cómo JavaScript construye el subtotal, el IVA del 19 % y el total, incluyendo el reto de descuento.

Datos de compra

Los precios se actualizan al seleccionar un producto.

Se obtiene según el producto elegido.

Cuenta de compra

Los resultados se muestran al calcular.

Selecciona un producto e indica una cantidad para obtener el total.

Fórmula aplicada

Subtotal = precio × cantidad. El IVA corresponde al 19 % del subtotal. El descuento se aplica sobre el subtotal antes de sumar el IVA.
